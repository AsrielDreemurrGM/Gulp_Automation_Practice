<h1>Gulp Automation Practice</h1>
<p>
    Este README também está disponível em <a href="./README.pt-br.md">Português</a>.
</p>
<p>
    A practice project for experimenting with <strong>Gulp</strong> and its plugins
    to automate common front-end tasks such as compiling Sass, compressing JavaScript,
    and optimizing images.
</p>
<h2>About</h2>
<p>
    This project was created as an exercise to understand and configure
    <strong>Gulp 4</strong> as a task runner for front-end workflows.
    The <code>gulpfile.js</code> includes functions for compiling SCSS into CSS,
    minifying JavaScript files, and optimizing images.
    It also uses the watch feature to automatically re-run tasks when files are changed.
</p>
<h2>Technologies Used</h2>
<ul>
    <li>JavaScript (Node.js)</li>
    <li>Gulp 4</li>
    <li>Sass (SCSS)</li>
    <li>Gulp Plugins: gulp-sass, gulp-uglify, gulp-imagemin, gulp-watch</li>
    <li>HTML5 (basic structure)</li>
</ul>
<h2>Features</h2>
<ul>
    <li>Compile SCSS files into CSS;</li>
    <li>Minify and compress JavaScript files;</li>
    <li>Optimize and reduce image sizes;</li>
    <li>Automatic task re-execution with Gulp Watch;</li>
    <li>Organized source and build folders for output management.</li>
</ul>
<h2>Notes</h2>
<p>
    This repository is a learning-focused project and does not include
    a live demo or hosted deployment. Its purpose is to practice using Gulp
    as a task runner and better understand automation in front-end development.
</p>
